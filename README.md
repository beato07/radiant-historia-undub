## Description
An automated Python utility to build a Japanese audio undub for Radiant Historia: Perfect Chronology (3DS).

## Requirements
Before starting, make sure you have:
1. An English `.cia` file of the game. You can dump and decrypt it using [GodMode9](https://gist.github.com/PixelSergey/73d0a4bc1437dbaa53a1d1ce849fdda1).
2. The original Japanese audio files placed in the `mods/romfs/Sound/se_voice` directory.
3. Python 3.x installed (if applicable).

## Setup
1. Drag and drop your decrypted `.cia` file onto `script.bat`.
2. Select your region when prompted in the console.
